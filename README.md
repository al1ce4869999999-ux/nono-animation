# nono-animation

画像のしっぽを選択し、指定した付け根を中心に揺らす静的 HTML アプリです。

## 使い方

1. 画像を読み込みます。
2. 「しっぽを囲む」を押し、指またはマウスで輪郭を囲んで離します。
3. 画像上の付け根をタップします。ピンクの点が回転の中心です。
4. 「▶ ふりふり」で再生し、「■ 停止」で停止します。

選択が小さすぎる場合、タッチが中断された場合、付け根が未指定の場合などは画面に理由を表示します。囲み直すと前の選択と付け根はリセットされます。

## 開発と動作テスト

外部サービスやビルドは不要です。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Python の Playwright パッケージと `/usr/bin/chromium` がある環境で、次を実行します。

```sh
python3 tests/browser_smoke.py
```

モバイル表示で Pointer Events と Touch Events の両経路、座標変換、選択の中断・再試行、付け根指定、再生・停止・再開、エラーメッセージを確認します。WebKit がインストール済みなら `BROWSER=webkit` でも実行できます。この自動テストは iPhone Safari 実機での確認を代替するものではありません。
