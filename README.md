# のののアニメ工房 (Nono Motion Studio)

iPhone Safariを中心に、イラストのしっぽを動かすブラウザ完結型アニメーション編集ツール。サーバーへの画像アップロードやAPIキーは不要です。

## 使い方
1. 画像を読み込み「しっぽを囲む」を選択。指で輪郭をなぞって離す。
2. しっぽの付け根をタップ。
3. 動きのプリセット（ふりふり／うれしい／ゆったり／おずおず）を選び、速度や角度を調整。
4. 再生して確認し、PNG静止画またはブラウザ対応時に動画を保存。

## 追加機能（2026-10-18）
- 「＋ パーツを追加」で、いまのパーツを確定し、次のパーツを囲む。耳・手・しっぽを同時に動かせます。「最後を削除」で戻せます。
- シーン入力から「うれしい」「ゆったり」「おずおず」などの簡単なキーワード判定をし、アニメーションのプリセットを選択します。LLMへのAPI通信はしません。
- PNG静止画、対応ブラウザでの短い動画、制作データJSONを保存できます。
- 制作JSONは元画像をデータURLとして含むため、画像次第でファイルが大きくなります。秘密の画像は共有しないでください。
- パーツの下の背景は近傍色を使った簡易穴埋めです。複雑な背景では不自然になります。

## 制約・今後の課題
- パーツを切り抜き、回転描画します。背景は近傍から採った単一色で穴埋めします。複雑な絵では違和感が生じます。
- 動画保存はCanvas captureStreamとMediaRecorderの対応状況に依存。特にiPhone SafariではMP4録画可能性を実機で要確認。未対応時は画面に理由を表示。
- ツールは文章からシーン全体を動画生成するAIではなく、イラストのパーツを動かす無料のローカル編集機能です。将来的にシーン入力・キャラ固定・AI動画API統合へ拡張予定。
- 動画録画の「秒数」は実時間に基づき、画面をバックグラウンドにすると不安定になる場合があります。

## テスト
既存の `tests/browser_smoke.py` は画像読み込み・輪郭選択・タッチフォールバック・付け根・再生停止などを対象とします。新UIと動画エクスポート機能は別途ブラウザE2EとSafari実機での検証が必要です。

静的HTMLのみなのでビルド不要。GitHub Pagesなどの静的ホスティングで動作します。

## オフライン解析エンジン
`analyzer.js` を追加。外部API・キー不要で以下を実行します。

- `NonoAnalyzer.analyze(text)`：最大20節の語句ベース動作解析。対象・動き・根拠語・暫定信頼度を返します。数値は統計的に校正した確率ではありません。
- `NonoAnalyzer.imageStats(imageData)`：明るさ、コントラスト、簡易輪郭変化量。画像の意味やキャラクターの部位を識別するものではありません。
- `NonoAnalyzer.sample(options)`：sway／bounce／tremble／holdの動き波形。

**検証**：構文チェック、喜び→怖がる2節解析、波形の有限数値、単色画像統計の基本ケースを確認済み。Safari実機・動画保存・回帰E2Eは未検証です。

**設計境界**：現段階はルールベースの解析であり、汎用AIモデルの画像認識や動画生成ではありません。MediaPipe等のオンデバイスモデルを使う案は、メモリ負荷、ライセンス、Safari互換性と端末上の性能を検証してから導入します。

## 全自動モード（実験的）
画像を選ぶと解析が自動起動し、色で背景から独立した小領域を探索します。縦長かつ画像の側方にあり、複数候補が競合しない場合にのみ、候補を切り抜いて回転再生します。**部位の意味を理解する仕組みではなく、特に身体とつながるしっぽ・室内背景・似た色の耳では失敗します。** 領域が不確実なら再生せず、必要に応じて従来の手動モードを使います。実機確認前で、成功率は未測定です。
